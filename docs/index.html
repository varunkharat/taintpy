taintpy

Paste Python code. taintpy reports where untrusted input can reach a dangerous call, and shows the path it takes.

What does this do?

Many security bugs have the same shape: text an attacker controls, like a form field or a command-line argument, travels through a program until it reaches something dangerous, like a shell command or a database query.

taintpy reads Python code without running it, marks untrusted input as tainted, and follows it through variables and function calls. It reports a problem only when tainted data can actually reach a dangerous call, and it shows every step of the path so you can check it yourself.

Try a sample from the menu, then click a finding to see its path highlighted on the code.

Ctrl+Enter also runs it.
